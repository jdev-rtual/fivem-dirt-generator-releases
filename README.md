# FiveM Dirt Map Generator: releases

Built downloads of **FiveM Dirt Map Generator**, which generates procedural dirt maps for GTA V / FiveM vehicles
(`.yft`). It previews the dirt live in a GTA-style 3D view with a dirt-level slider and embeds the maps straight
into the vehicle file.

Grab the latest `DirtMapGenerator.exe` from [Releases](../../releases/latest). Installed copies update
themselves from here. Each exe has a matching `.sha256` file, and the app refuses any download that doesn't match it.

Requires the .NET 10 Desktop Runtime (x64). The source code is maintained privately.
